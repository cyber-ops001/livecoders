# Live Coders v20.6.7

## Profile content tabs
- Added Posts, Blogs, and Reels tabs to user profiles.
- Profile content is classified using the same rules as Home:
  - one-page content → Post
  - multi-page content → Blog
  - `post_type = reel` → Reel
- Tabs switch content in-place without changing routes or reloading the page.
- Added responsive dark-theme styling for the profile tabs.
